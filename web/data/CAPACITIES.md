# Опубликованные мощности морских портов

## Покрытие бассейнов

Файл `basin-capacities.json` содержит 18 наблюдений по трём бассейнам. Подтверждены шесть срезов мощности, указанные ниже. Числа приведены в млн т в год.

| Дата среза | Год состояния в источнике | Балтика | Азово-Черноморский | Дальневосточный |
| --- | ---: | ---: | ---: | ---: |
| 01.01.2012 | 2011 | 292,2 | 231,0 | 162,7 |
| 01.01.2013 | 2012 | 303,8 | 259,1 | 188,1 |
| 01.01.2014 | 2013 | 307,8 | 264,0 | 191,9 |
| 01.01.2017 | 2016 | 334,5 | 373,4 | 204,0 |
| 01.01.2018 | 2017 | 345,8 | 382,8 | 226,3 |
| 01.01.2019 | 2018 | 361,4 | 390,4 | 239,3 |

Срез 01.01.2012 взят из столбца «2011 г. факт» таблицы 11 ранней стратегии Росморпорта. Дата представляет эту годовую базу на границе года. [Официальный PDF, страницы 43–44](https://www.rosmorport.ru/media/File/State-Private_Partnership/strategy_2030.pdf).

Срез 01.01.2013 взят из базовых столбцов 2012 года в приложении 5 стратегии Росморпорта. Дата представляет эту годовую базу на границе года. Прогнозные столбцы 2015, 2020 и 2030 исключены из набора наблюдений. [Официальный PDF, страница 132](https://www.rosmorport.ru/uploadify/988-f11a995b44861c9c2b1c7e0f502b433e.pdf).

Срез 01.01.2014 имеет явную дату в таблице 1 другой редакции стратегии. Используется столбец номинальной мощности причалов. В титуле документа стоит «Москва 2013», тогда как заголовок таблицы указывает 1 января 2014. Поэтому точная дата публикации этого выпуска требует уточнения. [Официальный PDF, страница 14](https://www.rosmorport.ru/media/File/strategy.pdf).

Три следующих среза взяты из отчёта Счётной палаты за 2020 год. В таблице прямо указаны даты 01.01.2017, 01.01.2018 и 01.01.2019. Здесь сохранена копия первичного отчёта, опубликованная PortNews. [Отчёт, страница 8](https://portnews.ru/upload/basefiles/2240_chschchpechtpnpachjapppaplpachtpa.pdf).

Покрытие бассейнов неполное. Для остальных лет диапазона 2012–2026 в наборе отсутствуют подтверждённые точки. Наличие истории перевалки за эти годы позволяет показывать их в интерфейсе и явно указывать отсутствие сопоставимой мощности.

## Поля записи бассейнов

| Поле | Значение |
| --- | --- |
| `year` | Год начала применения среза при реконструкции. Совпадает с годом `asOf`. |
| `asOf` | Дата привязки среза в реконструкции. Для годовых баз 2011 и 2012 отнесение к 1 января следующего года является правилом модели. |
| `measuredYear` | Предыдущий календарный год, к концу которого относится срез. |
| `basin` | `baltic`, `azov` или `far_east`. |
| `annualCapacity` | Установленная годовая мощность, млн т в год. |
| `unit` | `million_tonnes_per_year`. |
| `measurement` | `installed`. |
| `sourceUrl`, `sourceTitle`, `sourcePage` | Происхождение и страница документа. |
| `publishedOn` | `null`, когда точная дата публикации не установлена. |
| `publicationYear`, `dateNote` | Год документа и пояснение точности дат. |
| `localSourceUrl` | Путь к сохранённой копии PDF и нужной странице. |
| `reconstructionOnly` | Признак проверки с использованием позднее найденных данных о мощности. |

Деление годовой мощности на четыре даёт равномерный квартальный эквивалент. Для эффективной мощности конкретного квартала нужны сезонность, даты ввода оборудования, специализация грузов, ремонты и ограничения подходов. Использование среза 1 января для кварталов соответствующего года явно задаётся как допущение реконструкции.

Точные даты первоначальной публикации этих срезов пока не установлены. Дата утверждения аудиторского отчёта сама по себе не определяет день его доступности. Это ограничение учитывается при трактовке проверки прошлых решений.

## Национальный ряд

Файл `national-capacities.json` содержит 25 точек установленной мощности всех российских портов за 2000–2024 годы по графику АМТП. `year` обозначает год графика, `asOf` — границу следующего года, `stockState` равен `year-end`. Поля `value` и `annualCapacity` содержат одно значение для графика и расчётов. [Первичный график АМТП](https://www.morport.com/sites/default/files/inline/files/gruzooborot_i_moshchnosti_morskih_portov_rossii_na_01.01.2025_s_procentami_1.pdf).

Национальный ряд показывает 846,7 млн т за 2012 год, а базовый столбец стратегии Росморпорта — 846,2 млн т. Сохранены обе опубликованные версии с их источниками. Национальный агрегат показывается отдельно от бассейнов. Его распределение по бассейнам требует дополнительных исходных данных.
