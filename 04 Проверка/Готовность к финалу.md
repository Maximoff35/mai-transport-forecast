# Проверка готовности к финалу

Версия 13 ноября 2026. Документ фиксирует реализованные требования и оставшиеся внешние условия. Исходный архив чемпионата и заочная сдача не изменялись.

| Требование | Состояние и проверка |
| --- | --- |
| Пользователь и проблема | Аналитик планирует ресурс и ремонт. Контекст есть в начале презентации и документах. Перевалка не объявлена скрытым спросом. |
| Первый экран | Начальная страница показывает текущий план, четыре ползунка, график и превышение до/после. История и источники вынесены на отдельные страницы. |
| Единый расчёт | График, карточки действий, пояснение и экспорт используют один ответ движка. Исторические факты не меняются ползунком. |
| Сценарии −5 / 0 / +5% | Контрольные результаты Балтики: 0 / 0; 2 / 0; 5,3 / 2,3 млн т до/после. Сброс задаёт известное состояние. |
| Минимально необходимый резерв | Потребность показана по каждому кварталу рядом с результатом, отдельно от заданного резерва на один квартал. |
| Вторая гипотеза | Перенос остаётся видимым при запрете, срок подписан. На 13.11.2026 крайняя дата 03.10.2026 уже прошла. |
| Горизонт графика | Выбор 1–4 кварталов не отключает основной план на два полных квартала. |
| История | 58 кварталов, выбор видимого диапазона, сравнения с прошлым кварталом и прошлым годом, источники и даты. |
| Месячные факты | Балтика: апрель 21,6, май 22,5, июнь 21,9. Сумма 66,0 млн т. Недельный прогноз не заявлен. |
| Проверка прогноза | График факт/прогноз на шести общих целях, три метода и четыре горизонта. MAE объяснена как средний размер ошибки и меняется с выбранным методом. |
| Сильный контроль действий | Видны исходный план, выбранная мера и резерв в каждом окне, число назначений, успешные и неудачные окна. |
| Ретроспектива | Вся история сохранена. Опубликованные мощности отделены от условных 68. Разрывы обозначают пропуски. Деньги не объявлены подтверждённой прибылью. |
| Источники мощности | 18 значений по трём бассейнам на шесть дат и Россия 2000–2024 отдельно. Первичные PDF сохранены, есть ссылки и SHA-256. Полный бассейновый ряд пока не восстановлен. |
| CSV и сервер | Предпросмотр, сохранение набора в браузере, контроль конфликтов и пропусков, расчёт по запросу через собственный API. Официальный API АМТП не заявлен. |
| Автономный резерв | Клиентский расчёт и отдельное `Демо.html` с исходным срезом. Пересборка, JavaScript-проверка и две изменённые конфигурации прошли. |
| Материалы защиты | Восемь слайдов, паспорт на двух страницах, полный сценарий, рассказ на 60–90 секунд, карточка и подготовка команды. |
| Реальный пилот | Протокол подготовлен. Проведённый операторский пилот не заявлен. Нужны заявки, эффективные мощности и затраты терминала. |

Автоматические проверки подтверждают арифметику и поведение на проверенных случаях. Они не заменяют проверку модели на данных оператора, не доказывают причинный финансовый эффект и не означают, что команда уже отрепетировала выступление.

Последний проход: 44 теста веб-приложения, проверка TypeScript и production-сборка четырёх страниц прошли. Автономный комплект прошёл `rebuild.py`, `verify-demo.cjs` и `verify-config.py` с двумя изменёнными конфигурациями. В браузере повторены переходы страниц, сохранение поправки, оба режима мощности, переключение метода и сценарии −5 / 0 / +5%. Первый экран проверен на 1366 × 768. Сохранены три актуальных резервных кадра. Восемь слайдов и обе страницы паспорта просмотрены после рендеринга.

В автономном шаблоне также исправлена сценарная линия: +5% меняет зелёный пунктир, сохраняя исторические точки и базовый прогноз. Горизонт 1–3 не скрывает действия для I–II кварталов 2027. Добавлены ползунки, полный сброс и видимые недоступные меры. После пересборки повторно прошли все 363 сценарных сопоставления, 12 горизонтов и конфигурационные проверки. Изменение линии и сохранение действий при коротком горизонте подтверждены в браузере.

## Что остаётся за пределами готового прототипа

Реальные эффективные мощности по каждому кварталу, отклонённые заявки, стоимость мер и полученная оплата требуют данных оператора. Публичные годовые мощности не восстанавливают их автоматически. Годы без подтверждения остаются пропусками.

До выхода команда должна сама провести репетицию, проверить устройство показа и резервную копию. Консультация с экспертом не отмечается проведённой без фактической встречи и записи результата.
