# Прогноз нагрузки на морские порты

Для демонстрации откройте **Демо.html** обычным двойным щелчком. Интернет и установка не нужны. На странице можно менять нагрузку, мощности и сроки согласования. **Лаборатория.html** содержит двадцать расширений, объяснение каждого результата и таблицы проверки.

## Прогноз и история

В начале демо выберите бассейн и горизонт 1–4 квартала от среза данных. График показывает историю и прогноз. В таблице для каждого прогноза указаны прошлогодний ориентир и публикация источника. Раскрывающийся блок содержит все 18 наблюдений.

Срез заканчивается II кварталом 2026 года, поэтому горизонты 1–4 соответствуют III–IV кварталам 2026 и I–II кварталам 2027. Дата сценарного решения не сдвигает исторический срез. Для сравнения мер на I–II кварталы 2027 нужны оба этих периода: блок мер открывается при горизонте 4.

## Единые параметры

planning-inputs.json задаёт базовую мощность, ремонтную потерю, резерв, допустимость переноса, дату решения, сроки согласования и начальный горизонт. После изменения выполните python rebuild.py: обновятся CLI-результаты, демо, сетка сценариев, ретропроверка действий и лаборатория. Указанные в командной строке параметры переопределяют соответствующие значения только для этого запуска.

Изменения полей в браузере относятся к текущему сценарию и не записываются в JSON. Паспорт, презентация и карточка защиты содержат зафиксированные числа; после изменения вводных их нужно сверить отдельно.

## Три коротких примера

1. **Сроки влияют на решение.** Выберите Азово-Черноморский бассейн. При исходной дате 12.11.2026 и сроке согласования 90 дней перенос ремонта в I квартал исключён. Выключите «Учитывать сроки согласования», чтобы сравнить заранее согласованные действия. В этом режиме перенос уменьшает превышение до 4,7 млн т.
2. **Нужен ли резерв.** На Балтике при исходной мощности и нагрузке −5% хватает базового плана. Верните 0% и получите потребность в резерве.
3. **Новая территория.** Выберите Дальневосточный бассейн. Откройте записку о сценарии и сопоставьте её с таблицей 09 в лаборатории.

После изменения кнопка «Скачать записку о сценарии» сохраняет вводные и результат. В evidence/06-memo-example.txt есть проверенная выгрузка для Балтики с прогнозом и сравнением мер.

## Повторить расчёты

Нужен Python 3.10 или новее. В Windows можно использовать py вместо python.

```text
python forecast.py --basin baltic
python forecast.py --basin azov
python forecast.py --basin far_east
python forecast.py --basin baltic --shock-percent 5
python forecast.py --basin baltic --horizon 2
python verify-config.py --node путь_к_node
python rebuild.py
```

forecast.py печатает прогноз и сравнение заранее согласованных мер. Для календарно допустимого вывода используйте демо или evidence/13-calendar-qualified-actions.csv. rebuild.py пересобирает все таблицы и оба HTML, затем запускает проверки. Он читает локальные данные без скачивания и публикации.

## Файлы

| Файл или папка | Содержание |
| --- | --- |
| asop-verified.csv | 18 накопленных итогов по трём бассейнам, даты и ссылки. |
| planning-inputs.json | Единые начальные условия, горизонт, стресс-профили и критерии пилота. |
| config.py | Общая загрузка и проверка параметров. |
| verify-config.py | Сквозная проверка пересборки на изменённых параметрах. |
| checks.py | Аудит публикаций, чувствительность к PDF-компараторам, сверка периода и перенос метода. |
| planning.py | Стрессы, минимакс, резерв, календарь, грузы, узел, накопление, ремонты и инфраструктура. |
| pilot.py | Оценка журнала пилота. |
| holdout.py | Сверка нового наблюдения с прогнозом из архивного среза. |
| prepare.py и reports.py | Сборка демо, лаборатории и отчёта. |
| evidence | Таблицы, протокол проверки и реестр результатов. |
| sources | 21 первичный документ со ссылками и SHA-256 в manifest.json. |

В planning-inputs.json можно изменить условия и затем запустить rebuild.py. Текущие даты и горизонты относятся к срезу II квартала 2026. При замене среза нужно согласованно обновить плановый период.

## Как читать результаты

Наблюдаемая история — перевалка АСОП в млн тонн. Квартальный объём равен разности накопленных итогов внутри года. Между публикациями есть расхождения. Основной ряд сохраняет абсолютные уровни новостей, отдельный стресс использует проверенные значения PDF.

Мощности, потери, сроки, нормы и расписания — заданные условия. Расчёт оценивает превышение модельного потока над доступной мощностью. Реальные заявки, скрытый спрос и очередь в этих публикациях отсутствуют.

Проверка действий на истории охватывает по пять перекрывающихся окон на бассейн. Целевые кварталы начинаются после публикации входного среза. Меры считаются заранее согласованными. Суммы по окнам нельзя трактовать как общий операционный эффект.

В пунктах 17–18 III–IV кварталы 2027 используют условный сезонный профиль за пределами проверенного горизонта. В пункте 19 из Росморпорта взята годовая мощность, а сроки ввода и разгон заданы для сценария.

Сверка III квартала 2026 реконструирована 9 ноября. Вторичный итог имеет неподтверждённый охват и вынесен за основную оценку точности. В учебном примере пилота сохраняется маркировка synthetic.
