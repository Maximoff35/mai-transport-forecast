# Проверка веб-приложения

Очная версия 13 ноября 2026 года. Основной путь — серверный расчёт по исходному CSV или данным, которые аналитик подтвердил в предпросмотре.

| Проверка | Результат |
| --- | --- |
| Балтика, 13.11.2026, 68 / 4 / 3 | Дефицит 2,0 млн т, с резервом 0,0. Перенос даёт 0,3 условно и недоступен по сроку. |
| Поправка +5% | Дефицит 5,3 млн т, после резерва 2,3. График и вывод пересчитываются. |
| Поправка −5% | Дефицит 0,0 млн т. Дополнительная мера для покрытия дефицита не требуется. |
| Юг и режим сравнения | Текущая доступная мера оставляет 5,7 млн т. В режиме заранее согласованных мер перенос оставляет 4,7. |
| Месячные факты Балтики | Апрель 21,6, май 22,5, июнь 21,9 млн т. Сумма 66,0 млн т. |
| Выгрузка JSON | Для исходного сценария в файле I–II кв. 2027, единица «млн т», превышение 2,0 / 0,0 / 0,3. |
| Короткий горизонт графика | При 1 квартале план на I–II кв. 2027 остаётся доступным. |
| Потеря больше мощности | Интерфейс просит исправить условия, расчёт по прежним значениям скрыт. |
| Данные на 13.11.2026 | Исходный срез заканчивается II кв. 2026. Интерфейс предлагает загрузить факт за III квартал, если итог опубликован. |
| Предпросмотр CSV | Добавление одной тестовой строки Балтики за III кв. 2026 показало её период, объём и пропуски по другим бассейнам. |
| Применение и повторное открытие | Тестовое наблюдение отобразилось в истории и сохранилось после перезагрузки. Возврат к исходному набору восстановил проверенный срез. |
| Первый экран 1366 × 768 | Видны четыре ползунка, график мощности, дефицит до и после меры и статус переноса. |

Автоматические проверки охватывают формулу, даты публикаций, три метода прогноза, контроль с резервом в каждом окне, парсинг исходного CSV и новых файлов, ошибки HTTP и пересчёт с расширенной историей. Отдельно прошли пересборка автономной версии и проверка двух изменённых конфигураций. Тестовые значения для импорта используются только для проверки программы.

Для показа на другом компьютере держите локальную копию презентации, паспорта и `03 Инструмент/Демо.html`. Дополнительные кварталы из браузера переносятся через исходные CSV аналитика.
