# Прогноз нагрузки на морские порты

Проект команды **it plow** по кейсу МАИ 1 «Прогнозы для транспортного планирования».

Терминал принимает, хранит и перегружает груз. Ремонт временно уменьшает возможности оборудования, а грузопоток меняется по сезонам и направлениям. Аналитику нужно заранее согласовать ресурсы и время работ. Приложение показывает прогноз перевалки, превышение доступной мощности и эффект резерва или переноса ремонта с учётом сроков согласования.

В разделе «Ретроспектива» можно проверить прошлые решения и сравнить дополнительный операционный вклад после расходов. По умолчанию мера выбирается по максимальному прогнозному вкладу среди доступных действий, включая исходный план с нулевым дополнительным вкладом.

## Быстрый запуск

Для веб-приложения установите Node.js 22.13+ и выполните:

```sh
cd web
npm ci
npm run dev
```

Откройте адрес из строки Local (обычно [127.0.0.1:5173](http://127.0.0.1:5173)). В разделе данных можно скачать шаблон, загрузить CSV, посмотреть добавляемые кварталы и применить изменения. Загруженные данные сохраняются в этом браузере. Подробности запуска и форматов — в [руководстве приложения](web/README.md).

## Повторить расчёты

Нужен Python 3.10 или новее. Используется стандартная библиотека.

```text
cd "03 Инструмент"
python forecast.py --basin baltic
python forecast.py --basin azov
python forecast.py --basin far_east
python rebuild.py
```

В Windows можно использовать py вместо python. Параметры сценариев находятся в planning-inputs.json. rebuild.py обновляет результаты CLI, таблицы, демо и лабораторию по локальным данным. Проверка сквозного изменения параметров: python verify-config.py --node путь_к_node. Числа паспорта, слайдов и карточки защиты после смены вводных сверяются отдельно.

## Данные и границы применения

Веб-приложение содержит 58 кварталов с I квартала 2012 по II квартал 2026 по каждому из трёх бассейнов. Основной источник — Ассоциация морских торговых портов (АМТП). Годовой ряд России за 1991–2025 показан отдельно. В автономном демо используется исходный срез из 18 кварталов. [Источники и границы сопоставимости](web/data/README.md).

Контрольный пример Балтики охватывает 27 окон с I квартала 2013 по II квартал 2026 при выбранной истории с 2012 года. При условных мощностях 68/4/3 млн т выбор по ожидаемому вкладу уменьшает суммарное превышение с 31,6 до 23,6 млн т и назначает резерв пять раз. При заданных денежных параметрах сценарный вклад по фактическим объёмам равен 282 млн ₽. Постоянный резерв уменьшает превышение до 11,1 млн т за 27 назначений и даёт −696,125 млн ₽ вклада при той же цене мер. [Методика и контрольный пример](04%20Проверка/Ретроспектива.md).

Денежные параметры по умолчанию составляют 25% оплачиваемого прироста, 1 391 ₽/т тарифа, 1 000 ₽/т переменных расходов, 100 млн ₽ за резерв и 50 млн ₽ за перенос ремонта. Историческая перевалка подтверждается публикациями, а денежный результат зависит от этих предположений. Цены считаются постоянными, без НДС. Инфляция, дисконтирование и остальные расходы требуют дополнительных входов. [Происхождение параметров, формулы и ограничения](04%20Проверка/Экономика%20сценария.md).

Проблема согласования подтверждается сообщением АМТП о неполном использовании портового потенциала из-за невыполнения месячных планов РЖД. Это обосновывает проверку ресурсов по направлениям и срокам. [Сообщение АМТП от 09.12.2025](https://www.morport.com/rus/news/zasedanie-soveta-direktorov-associacii-morskih-torgovyh-portov-5).

Мощности, ремонтные потери, сроки и терминальные нормы задаются как сценарные условия. Для практического решения нужны заявки и эффективные мощности оператора. Сверка III квартала 2026 использует вторичный источник с неподтверждённым охватом и исключена из основной оценки точности.

## Исходные материалы чемпионата

Папка [00 Исходники](00%20Исходники/НАЧНИ_ЗДЕСЬ.md) содержит архив материалов чемпионата, собранный 13 ноября: исходное задание А1, общую презентацию кейсов, сопутствующие материалы экспертной сессии, сообщения из чата и иллюстрации. Начать можно с [НАЧНИ_ЗДЕСЬ.md](00%20Исходники/НАЧНИ_ЗДЕСЬ.md) или открыть [Обзор.html](00%20Исходники/Обзор.html) локально.

- [Полное задание А1](00%20Исходники/Оригиналы/1%20кейс.pdf) — основной документ постановки задачи.
- [Сообщения из чата](00%20Исходники/Сообщения_из_чата.md) — сохранённые требования и ответы организаторов с номерами сообщений; есть также JSON-версия.
- [Ссылки](00%20Исходники/Ссылки.md) — адреса внешних ресурсов. Содержимое внешних страниц не входит в этот архив.
- [Опись оригиналов](00%20Исходники/Опись.json) — происхождение, размеры и SHA-256 исходных PDF/PPTX.

Происхождение файлов, различия между публикациями и ограничения выгрузки описаны в «НАЧНИ_ЗДЕСЬ.md». Материалы в «00 Исходники» относятся к постановке кейса и общему контексту чемпионата. Папка «03 Инструмент/sources» отдельно хранит первичные статистические публикации, использованные в расчёте.

Очный пример использует дату решения 13 ноября 2026 года. При прогнозе 66 млн т и мощности 64 млн т во II квартале 2027 не хватает 2 млн т. Сценарный резерв 3 млн т закрывает дефицит. Перенос ремонта показан для сравнения, его срок согласования истёк 3 октября.

В рабочей папке хранится одно актуальное состояние. Предыдущие изменения сохраняются в истории Git.
