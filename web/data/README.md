# История грузооборота и импорт CSV

Встроенный набор охватывает 18 кварталов, с I квартала 2022 по II квартал 2026, для Балтийского, Азово-Черноморского и Дальневосточного бассейнов. Файл `verified-quarters.json` сохраняет накопленные значения и ссылки из `03 Инструмент/asop-verified.csv`. Квартальный объём рассчитывается как разность соседних накопленных итогов в пределах года. Для I квартала используется сам накопленный итог.

В месячной истории доступны апрель, май и июнь 2026 для всех трёх бассейнов. Месячный объём вычисляется из двух соседних накопленных итогов. Мартовский итог охватывает январь–март и служит базой вычитания для апреля. Даты, ссылки и контрольные суммы копий первичных публикаций сохранены в `monthly-manifest.json`. Новые данные поступают через CSV аналитика. Публичные публикации АМТП используются для проверки исходной истории.

## Форматы CSV

Сохраните файл в UTF-8. Допустимы BOM, запятая, точка с запятой или табуляция. Используйте один разделитель в файле. Десятичная запятая допустима, если поле заключено в кавычки или разделитель не запятая. Квартал записывается как `2026-Q3`. Бассейны обозначаются `baltic`, `azov`, `far_east`. Единица всех объёмов — млн т.

1. **Квартальные объёмы** — `quarter,basin,value`.
2. **Накопленные объёмы** — `quarter,basin,ytd_value`. Для II–IV кварталов требуется накопленный итог предыдущего квартала того же года. Он может быть во встроенной истории или в загружаемом наборе.
3. **Формат исходной таблицы** — `quarter,baltic_ytd_million_tonnes,azov_black_sea_ytd_million_tonnes,far_east_ytd_million_tonnes`. Одна строка добавляет до трёх наблюдений.

Во всех форматах можно указать `published_on` в виде `ГГГГ-ММ-ДД` и `source_url` с адресом публикации. Если дата отсутствует, приложение использует дату импорта как дату доступности строки. Для накопленного объёма датой доступности считается день, когда известны оба итога. Введите только завершённые кварталы.

Предпросмотр показывает добавляемые строки, совпадения и конкретные пропуски по бассейнам. При конфликте с сохранённым наблюдением импорт прекращается и указывает квартал. После подтверждения данные сохраняются в браузере. Источники новых строк отмечаются как требующие проверки.
