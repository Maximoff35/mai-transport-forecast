# Карточка защиты

## Рассказ за 30 секунд

Порт получает деньги за обработку груза. Ремонт уменьшает доступный ресурс, а резерв нужно заранее согласовать и оплатить. Продукт прогнозирует нагрузку, сравнивает доступные меры по ожидаемому денежному вкладу и проверяет их на истории. В готовом сценарии Балтики за 27 периодов получаем +282 млн ₽ после обработки и мер. Это оценка при явно заданных условиях, которую нужно проверить на данных терминала.

## Опубликованные мощности и условный пример

Сайт открывает текущий прогноз. В «Ретроспективе» по умолчанию годовая мощность из источника / 4, на всей истории с пропусками. Подтверждены 18 значений бассейнов на шесть дат. Для Балтики доступны 10 из 29 окон, в них базовой мощности хватает, дополнительный объём и вклад к исходному плану равны нулю. Это не доказывает отсутствия ограничений отдельных терминалов. Мощности соседних годов не подставляются.

Числа +282 млн ₽ и 27 окон ниже относятся к режиму «Условная мощность» с 68 / 4 / 3. Для показа этого примера выбрать режим вручную. Квартальные эквиваленты мощностей не являются измеренной эффективной мощностью квартала. Источники и PDF находятся на странице «Данные».

## Параметры примера

68 млн т мощность за квартал, ремонт −4, резерв +3. Сроки: резерв 45 дней, перенос 90. Деньги: 25% сокращённого превышения превращаются в дополнительный объём, тариф 1391 ₽/т, обработка 1000 ₽/т, резерв 100 млн ₽/назначение, перенос 50 млн ₽. Тариф найден для конкретной услуги, остальные значения сценарные. Методика и ссылки: [Экономика сценария](../04%20Проверка/Экономика%20сценария.md).

## Пример 2026H1

Решение 10.10.2025. Прогноз 68,1 / 67,7. Мощность 68 / 64, с резервом 68 / 67. Факт 64,3 / 66. По факту превышение 2 → 0 млн т. Денежный объём 500 тыс. т. Результат: 500 тыс. × 391 − 100 млн = +95,5 млн ₽. Ожидалось +193,25 млн ₽, ошибка прогноза видна.

## Быстрые ответы

- Проблема: согласовать поток, ремонт и ресурс по срокам. АМТП 09.12.2025 подтверждает проблему рассогласования планов, но не результат нашего продукта.
- Перевалка — уже обработанный объём. Историческая проверка использует его как нагрузку сценария и не доказывает реальные отказы клиентам.
- Сезонный прогноз берёт тот же квартал прошлого года. На шести общих целях 2025Q1–2026Q2 MAE горизонта 4: Балтика 3,6 млн т, юг 6,2, восток 4,93. Эти шесть целей отличаются от 27 окон управленческой проверки.
- Выбор использует только данные, опубликованные до решения. Факт раскрывается после выбора.
- Без денежного критерия прежний ориентир сохраняется: 31,6 → 20,6 млн т и семь резервов. С денежным критерием он может отказаться от дорогой меры.
- Прогноз не гарантирует прибыль. При доле 10% и цене резерва 100 млн результат −204,5 млн ₽. При дешёвом резерве постоянное правило может выиграть.
- Рубли — операционный вклад сценария, не фактическая чистая прибыль и не обещание клиенту. Стоимость продукта, налоги и прочие расходы нужно учесть в пилоте.
- Новый CSV аналитик загружает сам. Интернет-API АМТП не заявляем. Расчётный API принадлежит нашему приложению.
- ChatGPT использовали для консультаций по методам, помощи с кодом и пояснениями, поиска ошибок.

## Показ

Начальная страница: текущий прогноз. Для денежного примера перейти в «Ретроспективу», нажать «Сбросить пример», выбрать «Условная мощность»: +282 млн ₽. Раскрыть параметры и статьи расходов. Пример 2026H1 открывается в разборе. В «Планировании» нажать «+5%»: после резерва остаётся 2,3 млн т. Вернуть «Базовый». Если сайт недоступен, продолжать по слайдам 3–5, где те же числа.
