# Ретроспектива решений и экономика

Выберите бассейн и диапазон в разделе «Ретроспектива». В каждой паре кварталов решение принимается до начала первого квартала по доступным тогда выпускам. Затем прогноз заменяется опубликованной перевалкой для оценки превышения мощности. Стратегии сравниваются при одинаковых сценарных условиях и календаре. Пары не пересекаются.

Балтика, диапазон I кв. 2012 – II кв. 2026, мощность 68, ремонт 4 и резерв 3 млн т, сроки 45 и 90 дней. Первые два окна пропущены, поскольку им нужна история 2011 года. В остальных 27 окнах:

| Стратегия | Суммарный расчётный дефицит, млн т | Назначений резерва |
| --- | ---: | ---: |
| Исходный план | 31,6 | 0 |
| Выбор по прогнозу | 20,6 | 7 |
| Резерв в квартале ремонта | 11,1 | 27 |

Постоянный резерв уменьшил дефицит на дополнительные 9,5 млн т за 20 назначений. На одно дополнительное назначение приходится 475 тыс. т разницы в дефиците. Умножьте этот показатель на подтверждённую долю дополнительно обслуживаемых заявок и маржу на тонну, чтобы получить порог цены такого резерва. Это порог для данного сравнения и заданных мощностей.

В I полугодии 2026 на Балтике оба правила закрывают 2 млн т расчётного дефицита. На юге в том же окне выбор по прогнозу оставляет 8,7 млн т, резерв в квартале ремонта — 5,7 млн т. Сравнивайте по нескольким окнам, включая те, где выбор по прогнозу проигрывает.

Для того же диапазона и тех же входов по Азово-Черноморскому бассейну дефицит составил 109,1 / 89,7 / 71,3 млн т, а по Дальнему Востоку — 11,4 / 8,4 / 5,5. Порядок тот же: исходный план, выбор по прогнозу, резерв в квартале ремонта. Условия по мощности здесь одинаковы для иллюстрации поведения правила. Для общего денежного итога потребуются отдельные данные операторов по каждому бассейну.

Для оценки выручки требуется дополнительно обслуженный объём. Для оценки операционного вклада вычтите переменные затраты на этот объём и цену мер. Для сопоставления за несколько лет используйте входы в ценах одного периода либо считайте каждый период со своими входами. Общебассейновая перевалка не содержит отказов, задержек и дополнительных затрат оператора.

Открытый [прейскурант «Глобал Портс»](https://www.globalports.com/upload/iblock/b67/hvq174d2r1e2zqo2mjx61kyc414v369i/Prilozhenie-k-Uvedoml-1261_UK_2025_Tarify-na-perevalku-i-khranenie-gen.-gruzov-_KE_-_1_.pdf), таблица 1, содержит 1 391 ₽/т без НДС для конкретной схемы перевалки минеральных удобрений. Это цена услуги. Чтобы использовать её в оценке проекта, нужны сопоставимый грузопоток терминала, фактический контракт, маржа, стоимость резерва и необслуженные заявки. Публичный тариф не экстраполируется на общий объём бассейна.
