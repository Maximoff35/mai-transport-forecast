# История грузооборота и импорт CSV

Веб-приложение содержит 58 кварталов с I квартала 2012 по II квартал 2026 для Балтийского, Азово-Черноморского и Дальневосточного бассейнов. [Исторические выпуски](historical-quarter-totals.json) содержат накопленные значения, дату доступности, издателя и URL. [Срез 2022–2026](verified-quarters.json) сохраняет данные прежней версии. Квартальный объём равен разности соседних накопленных итогов одного года. Для I квартала используется сам накопленный итог. Дата доступности квартальной разности — более поздняя из дат двух выпусков.

Основной источник — публикации [Ассоциации морских торговых портов](https://www.morport.com/rus/content/statistika-0). Для некоторых периодов использованы датированные перепечатки АСОП и выпуск Минтранса. Для I квартала 2018 и I квартала 2019 взяты значения из PDF ассоциации, а в поле `published_on` указана консервативная дата доступности (конец следующего квартала). В выпуске за I квартал 2010 агрегат «Северо-Западный» включает арктические порты. В выпусках за 2011 встречаются другие обозначения, включая «Черноморский» и «Тихоокеанский». Без проверки сопоставимости состава портов эти выпуски оставлены за границей общего квартального ряда. [Выпуск 2010](https://www.morport.com/rus/publications/document1069.shtml), [итоги 2011](https://www.morport.com/rus/publications/document1229.shtml).

[Годовой ряд по России](national-annual.json) содержит 1991–2025 годы. За 1991–1999 использовано приложение 2 к стратегии Росморпорта, за 2000–2024 — сводный график АСОП, за 2025 — годовой выпуск АСОП. Ряд отражает опубликованные версии источников, в том числе пересмотры, и используется отдельно от квартальных вычислений.

В месячной истории доступны апрель, май и июнь 2026 для всех трёх бассейнов. Месячный объём вычисляется из двух соседних накопленных итогов. Мартовский итог охватывает январь–март и служит базой вычитания для апреля. Даты, ссылки и контрольные суммы копий первичных публикаций сохранены в `monthly-manifest.json`. Новые данные поступают через CSV аналитика. Публичные публикации АМТП используются для проверки исходной истории.

## Данные для ретроспективы и денежные параметры

Диапазон I кв. 2012 – II кв. 2026 даёт 27 непересекающихся окон проверки начиная с I кв. 2013. Два окна 2012 года требуют квартальных данных 2011 года и явно пропускаются. В каждом окне выбор использует выпуски, доступные к дате решения. Опубликованная перевалка затем подставляется для проверки результата.

По умолчанию ретроспектива выбирает меру по максимальному ожидаемому дополнительному операционному вкладу. Параметры примера составляют 25% оплачиваемого дополнительного объёма, 1 391 ₽/т тарифа, 1 000 ₽/т переменных расходов, 100 млн ₽ за назначение резерва и 50 млн ₽ за перенос ремонта. Эти параметры хранятся отдельно от исторических наблюдений. Источник цены 1 391 ₽/т — строка Н2 таблицы 1 конкретного прейскуранта на перевалку удобрений. Остальные значения требуют проверки у оператора. [Источник тарифа](https://www.globalports.com/upload/iblock/b67/hvq174d2r1e2zqo2mjx61kyc414v369i/Prilozhenie-k-Uvedoml-1261_UK_2025_Tarify-na-perevalku-i-khranenie-gen.-gruzov-_KE_-_1_.pdf).

При вводных 68/4/3 млн т выбранная политика на Балтике даёт 23,6 млн т расчётного превышения и 282 млн ₽ сценарного вклада по фактическим объёмам за 27 окон. Оплачиваемый прирост и расходы задаются предположениями. Цены постоянные, без НДС, инфляция и дисконтирование требуют отдельных расчётов. [Методика проверки](../../04%20Проверка/Ретроспектива.md), [формулы и условия денежного примера](../../04%20Проверка/Экономика%20сценария.md).

## Форматы CSV

Сохраните файл в UTF-8. Допустимы BOM, запятая, точка с запятой или табуляция. Используйте один разделитель в файле. Десятичная запятая допустима, если поле заключено в кавычки или разделитель не запятая. Квартал записывается как `2026-Q3`. Бассейны обозначаются `baltic`, `azov`, `far_east`. Единица всех объёмов — млн т.

1. **Квартальные объёмы** — `quarter,basin,value`.
2. **Накопленные объёмы** — `quarter,basin,ytd_value`. Для II–IV кварталов требуется накопленный итог предыдущего квартала того же года. Он может быть во встроенной истории или в загружаемом наборе.
3. **Формат исходной таблицы** — `quarter,baltic_ytd_million_tonnes,azov_black_sea_ytd_million_tonnes,far_east_ytd_million_tonnes`. Одна строка добавляет до трёх наблюдений.

Во всех форматах можно указать `published_on` в виде `ГГГГ-ММ-ДД` и `source_url` с адресом публикации. Если дата отсутствует, приложение использует дату импорта как дату доступности строки. Для накопленного объёма датой доступности считается день, когда известны оба итога. Введите только завершённые кварталы.

Предпросмотр показывает добавляемые строки, совпадения и конкретные пропуски по бассейнам. При конфликте с сохранённым наблюдением импорт прекращается и указывает квартал. После подтверждения данные сохраняются в браузере. Источники новых строк отмечаются как требующие проверки.
