Автоматические проверки охватывают формулу, даты публикаций, три метода прогноза, контроль с резервом в каждом окне, парсинг исходного CSV и новых файлов, ошибки HTTP и пересчёт с расширенной историей. Отдельно прошли пересборка автономной версии и проверка двух изменённых конфигураций. Тестовые значения для импорта используются только для проверки программы.

Для показа на другом компьютере держите локальную копию презентации, паспорта и `03 Инструмент/Демо.html`. Дополнительные кварталы из браузера переносятся через исходные CSV аналитика.


## Дополнительная проверка навигации и мощности

Сборка содержит четыре отдельных маршрута: текущий прогноз, история, ретроспектива и данные. Переход по меню изменяет маршрут без прокрутки одной длинной страницы. Поправка +5% сохраняется после перехода в историю и возврата. Начальная страница содержит текущий план без блока ретроспективы.

В ретроспективе режим опубликованных мощностей включён по умолчанию. Для Балтики при подтверждённых срезах оцениваются 10 из 29 окон, 19 пропущены: 17 без мощности, два без нужной истории прогноза. По условной мощности 68 сохраняются 27 окон и сценарный вклад +282 млн ₽. Переключение режима проверено в браузере. На странице данных показаны 18 значений, 25 общероссийских годовых мощностей отдельно, ссылки на источники и пять локальных PDF. Все контрольные суммы включены в манифест.

Потребность в резерве теперь показана по каждому кварталу рядом с итогом. Подпись среднего размера ошибки меняется вместе с методом графика. Статистическая проверка относится к базовому прогнозу, а не произвольной поправке нагрузки. Обязательный исходный срез, календарь и арифметические инварианты сохранены.

Автономный `Демо.html` обновлён через исходный шаблон. При +5% проверено изменение только сценарной линии, история и базовый прогноз сохранены. План мер остаётся видимым при горизонте 1. Недоступный перенос показан отдельной строкой со сроком. Ползунки и сброс проверены. После пересборки повторно прошли `verify-demo.cjs` и `verify-config.py`.
