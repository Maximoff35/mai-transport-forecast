# Прогноз нагрузки на морские порты

Проект команды **it plow** по кейсу МАИ 1 «Прогнозы для транспортного планирования».

Инструмент показывает историю и квартальный прогноз на горизонт 1–4 квартала, затем сравнивает резервирование мощности с переносом плановых работ. Вводимые сроки согласования определяют, какие действия ещё доступны. В проект входят двадцать расширений с расчётами и подтверждающими материалами.

## Быстрый запуск

Скачайте или клонируйте репозиторий. Откройте [Демо.html](03%20Инструмент/Демо.html) в обычном браузере. Файл работает локально без установки и интернета.

- [Лаборатория двадцати расширений](03%20Инструмент/Лаборатория.html) показывает результаты, ограничения и таблицы проверки.
- [Паспорт проекта](01%20Паспорт/Паспорт%20проекта.pdf) и [редактируемый текст](01%20Паспорт/Паспорт%20—%20текст%20для%20правок.md).
- [Презентация](02%20Защита/Защита.pptx) и [сценарий выступления](02%20Защита/Сценарий%20защиты.md).
- [Карточка защиты: объяснение цифр, показ демо и ответы](02%20Защита/Карточка%20защиты.md).
- [Отчёт по двадцати расширениям](03%20Инструмент/Результаты%2020%20расширений.md).
- [Описание данных и проверок](03%20Инструмент/Проверка%20данных%20и%20расчёта.md).

На странице GitHub HTML отображается как исходный файл. Для интерактивного показа откройте его из локальной копии.

## Повторить расчёты

Нужен Python 3.10 или новее. Используется стандартная библиотека.

```text
cd "03 Инструмент"
python forecast.py --basin baltic
python forecast.py --basin azov
python forecast.py --basin far_east
python rebuild.py
```

В Windows можно использовать py вместо python. Параметры сценариев находятся в planning-inputs.json. rebuild.py обновляет результаты CLI, таблицы, демо и лабораторию по локальным данным. Проверка сквозного изменения параметров: python verify-config.py --node путь_к_node. Числа паспорта, слайдов и карточки защиты после смены вводных сверяются отдельно.

## Данные и границы применения

История содержит 18 кварталов с I квартала 2022 по II квартал 2026 для Балтийского, Азово-Черноморского и Дальневосточного бассейнов. Наблюдаемый показатель — перевалка АСОП в млн тонн. Первичные выпуски, даты публикаций и 21 сохранённый документ доступны в папке sources. Верификация учитывает обнаруженные расхождения между новостями и PDF-компараторами.

Мощности, ремонтные потери, сроки и терминальные нормы задаются как сценарные условия. Для практического решения нужны заявки и эффективные мощности оператора. Сверка III квартала 2026 использует вторичный источник с неподтверждённым охватом и исключена из основной оценки точности.
